# 8086 Assembly — Image Convolution and Matrix Filtering

Academic project developed in x86 Assembly for an 8086-compatible environment. The main assignment explores matrix-based image processing, including convolution and boundary handling through padded data.

## Overview

This repository contains Assembly exercises focused on low-level programming and numerical data processing. The main program works with matrix/image-processing operations, while a separate source file contains a Fibonacci-related exercise.

## Repository Contents

- `trab.asm` — main assignment for matrix-based image processing and convolution.
- `fib.asm` — Fibonacci exercise.

## Concepts

- 8086 / x86 Assembly
- Low-level programming
- Matrix manipulation
- Image convolution and filtering
- Boundary processing and padding
- Numerical computation

## Running the Programs

The source files are intended for an 8086-compatible assembler and execution environment. DOSBox may be used as the runtime environment, depending on the assembler and toolchain available.

1. Set up DOSBox or another compatible DOS environment.
2. Make an 8086-compatible assembler available inside that environment.
3. Assemble the desired `.asm` file using the syntax supported by the installed assembler.
4. Run the generated program and follow any input prompts shown by the program.

The exact commands depend on the assembler and DOS setup used. Check the source file and the requirements of your chosen assembler before building.

## Purpose

This project records practical work with Assembly language, emphasizing direct manipulation of data and the implementation of numerical operations in a constrained, low-level environment.
